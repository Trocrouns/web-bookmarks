# 网站收藏

一个按「功能分类」整理的个人网站收藏页。同一个功能下可以放多个站点（各有收藏意义），
每条站点记名称、网址和一句收藏理由。

- 线上地址：<https://trocrouns.github.io/web-bookmarks/>
- 数据在 `data.json`，**所有人打开看到的都是这一份**
- 样式参考 Claude 官网：奶油底色、衬线标题、珊瑚色强调

## 怎么加网站

两种方式：

1. **在网页里加**：点 ＋ 保存到本机草稿（条目上会标「本机」），然后 ⋯ → 发布本机改动，
   把复制出来的 JSON 发给 DSH，由它写进 `data.json` 并推送。
2. **直接改 `data.json`**：在 GitHub 网页上打开这个文件，点铅笔图标编辑，改完提交，
   一两分钟后线上就更新了。格式：

```json
{
  "v": 1,
  "cats": [
    {
      "name": "反向搜图",
      "sites": [
        { "title": "TinEye", "url": "https://tineye.com", "note": "能按修改时间排序" }
      ]
    }
  ]
}
```

`note` 可空。`url` 不写 `https://` 会自动补上。
